# 💰 Expense Tracker

A simple and user-friendly **Expense Tracker Web Application** that helps users record, manage, and monitor their daily expenses.

## 🚀 Features

* 🔐 User Login & Signup
* 💰 Add and manage expenses
* 📊 Track spending
* 🗂️ Organize expense information
* 🖥️ Simple and responsive user interface
* ⚡ Fast and lightweight frontend
* 💾 Client-side data handling

## 🛠️ Technologies Used

* **HTML5** – Website structure
* **CSS3** – Styling and responsive design
* **JavaScript** – Application logic and interactions
* **Git & GitHub** – Version control and project management

## 📂 Project Structure

```text
Expense_Tracker/
│
├── login.html          # Login page
├── signup.html         # User registration page
├── auth.css            # Authentication page styling
├── auth.js             # Login/signup functionality
├── script.js           # Main application logic
├── style.css           # Main website styling
└── README.md           # Project documentation
```

## ⚙️ How to Run

### 1. Clone the repository

```bash
git clone https://github.com/almas63711/Expense_Tracker.git
```

### 2. Open the project

Navigate to the project folder:

```bash
cd Expense_Tracker
```

### 3. Run the application

Open `login.html` in your web browser.

You can also use **VS Code Live Server** for a better development experience.
